# AI PDF Chatbot

A local AI-powered PDF chatbot built with Python, Streamlit, FAISS, Sentence Transformers, and Ollama.

## Features

Upload PDF documents through a web interface

Extract text using PyMuPDF

Split documents into overlapping text chunks

Generate text embeddings using Sentence Transformers

Perform semantic search with FAISS

Generate answers using a local Qwen3 model via Ollama

Display relevant PDF page references

Maintain chat history during the Streamlit session

## Technologies Used

Python

Streamlit

PyMuPDF

Sentence Transformers

FAISS

Ollama (Qwen3:4b)
